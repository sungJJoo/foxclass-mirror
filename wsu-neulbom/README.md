# 우송대학교 WISE 늘봄 사이트

대학연계 늘봄학교 프로그램 사이트. 목원대 WISE 늘봄 사이트와 같은 계열의 정보 구조
(상단 유틸바 → GNB → 메인비주얼 → 퀵메뉴 → 사업소개/성과 → 프로그램 → 공지·갤러리 →
신청 배너 → 관련기관 → 푸터)를 따르되, 마크업·스타일·문안은 모두 새로 작성했습니다.

## 구성

```
wsu-neulbom/
├── index.html      메인 (비주얼 슬라이더 3종, 퀵메뉴, 사업소개, 성과, 프로그램, 공지·갤러리)
├── intro.html      사업소개 (개요 / 목표·전략 / 추진체계 / 추진경과)
├── programs.html   프로그램 (운영개요 / 분야별 / 학기일정 / 안전·품질)
├── apply.html      참여안내 (참여학교 신청 / 운영절차 / 강사지원 / 서식)
├── notice.html     알림마당 (공지사항 / 활동갤러리 / 보도자료)
├── contact.html    문의 (온라인 문의 / FAQ / 오시는 길)
├── css/style.css   전체 스타일 (CSS 변수 기반 토큰 · 반응형)
├── js/common.js    GNB · 슬라이더 · 탭 · FAQ · 카운터 · 스크롤스파이 (외부 의존성 없음)
└── images/         favicon.svg (사진 자산 추가 위치)
```

빌드 도구 없이 그대로 정적 호스팅하면 됩니다. 로컬 확인은
`python3 -m http.server` 후 `/wsu-neulbom/index.html`.

## 디자인 토큰

`css/style.css` 상단 `:root`에서 색·타이포·치수를 한 곳에 모아 관리합니다.

| 변수 | 값 | 용도 |
| --- | --- | --- |
| `--navy` / `--navy-deep` | `#002e6d` / `#001f4b` | 우송 계열 기본 색 |
| `--blue` | `#0b5fb0` | 링크·강조 |
| `--orange` | `#ff7a2f` | CTA·모집 배지 |
| `--green` | `#17a673` | 과학 분야·완료 상태 |

우송대 공식 CI 색상값이 확정되면 위 네 개만 교체해도 사이트 전체 톤이 바뀝니다.

## 실제 데이터로 교체할 부분

HTML 안에 `<!-- ... 교체 -->` 주석으로 표시해 두었습니다.

- **로고** — 헤더/푸터의 `.logo-mark` (현재 "W" 텍스트 마크) → 사업단 심볼 이미지
- **연락처** — 대표전화 `042-630-0000`, 이메일 `neulbom@wsu.ac.kr`, 주소는 임시값
- **성과 수치** — `index.html` `.stats` 의 `data-to` (참여학교 32 / 프로그램 48 / 학생 1,240 / 강사 86)
- **프로그램 내용** — 6개 과정의 학년·주차·정원은 표준 운영안 예시
- **게시판** — 공지·보도자료·갤러리 목록은 예시 데이터, 게시판 시스템 연동 필요
- **서식 파일** — `apply.html#forms` 의 `href="#"` → 실제 HWP/PDF 경로
- **사진** — 갤러리의 `.ph` 그라데이션 블록 → `<img>` 로 교체
- **지도** — `contact.html#map` 의 `.map-box` → 카카오맵/네이버지도 API 컨테이너
- **문의 폼** — `#inquiry-form` 은 현재 프런트 데모. `action` 지정 및 서버 접수 처리 필요

## 접근성 / 브라우저

- 본문 바로가기 링크, 시맨틱 헤딩, 모든 이미지·아이콘에 대체 텍스트 또는 `aria-hidden`
- GNB 드롭다운 키보드 접근(`focus-within`), 탭 좌우 방향키 이동, FAQ `aria-expanded`
- 슬라이더는 hover/focus 시 정지, 자동재생 정지 버튼 제공, `prefers-reduced-motion` 존중
- 1440 / 1024 / 720px 기준 반응형, 가로 스크롤 없음 (Chromium 확인)
